# Skill: UI/UX Specialist

## Description
هذه المهارة تمنح الوكيل الذكي قدرات متقدمة في تصميم واجهة وتجربة المستخدم (UI/UX)، مع التركيز على تصميمات عصرية وتجاوبية (Responsive) لمواقع الويب.

## Trigger (متى يتم استخدام هذه المهارة)
استخدم هذه المهارة عندما يطلب المستخدم إنشاء، تصميم، أو تحسين واجهات المستخدم، أو عند بناء مكونات الواجهة الأمامية (Frontend Components).

## Instructions (التعليمات)
1. **التصميم المتجاوب (Responsive Design):** اعتمد دائماً على Tailwind CSS لبناء واجهات تتناسب مع جميع الشاشات (الهواتف، الأجهزة اللوحية، والحواسيب).
2. **تجربة المستخدم (UX):** ركز على سهولة الاستخدام، وضوح الألوان (Contrast)، وسهولة القراءة.
3. **الجمالية والاحترافية:** قدم تصاميم عصرية تناسب مواقع الـ Portfolio للشركات (مثل Rabat Enseignes)، مع الحفاظ على كود نظيف ومنظم.
4. **التفاعل (Interactivity):** إذا لزم الأمر، اقترح أو أضف تأثيرات حركية خفيفة باستخدام مكتبات مثل Framer Motion أو GSAP لجعل الموقع أكثر حيوية.
